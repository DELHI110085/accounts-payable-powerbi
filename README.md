# Overview
This project analyzes vendor payment behavior using Power BI to identify delays, spending patterns, and performance trends across vendors.

## Overview Page
- Total Paid Amount
- Average Payment Delay
- Late Payments

## Vendor Analysis
- Compare vendor-wise payment delay
- Sum of Amounts by vendor

## Payment Delay Analysis
- Monthly trend of average payment delay
- Overdue paid invoices vs On Time paid invoices percentage
- Vendor-wise total delay days

## Key Insights
- TechMart shows highest average delay (16.17 days)
- BluePrints is the highest spend vendor
- Delay patterns are inconsistent over time, indicating operational inefficiency

## Tool Used
- Power BI (DAX,Visualization)

## Dataset
Accounts payable dataset used (Amount, DueDate, InvoiceDate, PaidDays, Status)

## Conclusion
PowerBI helped convert raw data into interactive dashboards, making it easier to identify payment inefficiencies and vendor performance trends
